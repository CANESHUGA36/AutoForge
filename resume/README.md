# 简历 · PDF 第一版草稿

面向 BOSS 直聘附件与 HR 打印的 **A4 一页浅色稿**。虚线下划线是待填项（姓名、学历、专业、电话等）。

右上角为证件照位（一寸比例 25×35）。把正式照片覆盖为 `resume/photo.jpg` 后重新导出即可，不必改版式。

## 导出 PDF

```bash
cd resume
npm install
npm run pdf
```

生成文件：

- `output/resume-zh.pdf` — 投递用
- `output/preview.png` — 整页预览

也可在 Chrome 打开 `index.html`，打印为 A4、打开「背景图形」、页眉页脚关掉。
